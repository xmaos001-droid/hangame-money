[1] 꼭 변경할 항목
index.html 에서 아래 문자열을 검색해서 실제 값으로 변경하세요.

1. YOUR_GITHUB_ID
   예: danbi123

2. YOUR_REPO
   예: hangame-money

3. https://open.kakao.com/o/REPLACE_ME
   실제 카카오 오픈채팅 주소

4. https://t.me/REPLACE_ME
   실제 텔레그램 주소 또는 아이디 링크

5. 01000000000
   실제 전화번호 (tel: 링크용, 숫자만)

6. 010-0000-0000
   화면에 표시할 실제 전화번호

7. +82-10-0000-0000
   JSON-LD 구조화데이터 안의 실제 전화번호

[2] GitHub Pages 업로드
- GitHub에서 새 Repository 생성
- 이 폴더의 index.html / styles.css / script.js / robots.txt / sitemap.xml 업로드
- Settings > Pages
- Source: Deploy from a branch
- Branch: main / root
- 저장
- 생성된 github.io 주소 확인

[3] 검색 노출 작업
- Google Search Console에 사이트 등록
- URL 검사에서 메인 주소 색인 생성 요청
- sitemap.xml 제출
- title/H1/본문은 페이지 내용과 실제 서비스에 맞게 유지
- 같은 키워드를 과도하게 반복하지 말 것
- 실제로 도움이 되는 고유 콘텐츠를 추가할 것

[4] 중요
코드만으로 Google 검색 1위가 보장되지는 않습니다.
검색 순위는 사이트 콘텐츠 품질, 신뢰도, 링크, 경쟁도, 사이트 이력 등 여러 신호에 따라 달라질 수 있습니다.
